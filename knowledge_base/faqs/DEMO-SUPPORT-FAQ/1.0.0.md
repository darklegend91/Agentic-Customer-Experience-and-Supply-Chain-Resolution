# Synthetic demo FAQ

This FAQ is fictional support-workflow training content. It is not a retailer's official answer and must not be presented as one.

## Where is my order?

The assistant can report the order status and the latest delivery event available in the authorized record. It should include when that record was checked and ask for the order reference if it cannot safely find the order.

## Tracking says delivered, but I did not receive the parcel

The assistant should report the recorded delivery scan, explain that the report and scan conflict, and route the case for review. It must not claim that the customer received the parcel.

## Can I return this item?

The assistant needs the authorized order item and an approved policy version that applies to the marketplace, item, and purchase date. If that evidence is missing, it should not promise a return or refund.

## My item arrived damaged

If an item arrived damaged, broken, or defective, ask which order item is affected and what damage the customer observed. Verify the caller's access before reading order details, then check the item record and the approved policy for that marketplace, item, and purchase date. Ask for additional evidence only when that policy requires it. If the applicable policy or required evidence is missing, explain that a support specialist needs to review the case. Do not promise a return, replacement, refund, or compensation based on a damage report alone.

## Where is my refund?

The assistant can report the status shown in the authorized return/refund record. A status check does not determine eligibility for another refund or guarantee when money will arrive.
