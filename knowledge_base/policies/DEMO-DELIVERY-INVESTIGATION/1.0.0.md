# Synthetic demo rule

This is fictional training content for the development fixture. It is not a retailer policy and is not approved for customer-facing use.

## Handling

Report only the order status and delivery events returned by an authorized read tool. Include the source timestamp. If the estimated delivery date has passed but no delivery event confirms receipt, propose an investigation or ask for the missing reference. Do not promise a delivery date, refund, or compensation.

If the source records show a delivered event while the customer reports non-receipt, state that the records conflict and route the case for human review. A delivered scan is evidence of a scan, not proof that the customer received the parcel.
