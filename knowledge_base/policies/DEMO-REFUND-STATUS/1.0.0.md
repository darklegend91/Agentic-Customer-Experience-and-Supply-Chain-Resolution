# Synthetic demo rule

This is fictional workflow guidance for the development fixture. It does not promise a processing time or monetary outcome.

## Handling

Report only the refund status returned by an authorized source, together with its source timestamp. If no refund record is available, say that the record was not found and route the case for review. Keep status lookup separate from refund eligibility.

The assistant may draft a proposal for review. It must not issue, approve, or claim that a refund or compensation has been executed.
