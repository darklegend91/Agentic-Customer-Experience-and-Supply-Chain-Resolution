# Loyalty and rewards investigation

## Recorded points balance

Report only the points balance and transactions returned by the authorized loyalty ledger. Include the ledger snapshot time and identify pending or reversed events. A ticket message, order total, or customer tier is not proof that points were earned.

## Expiry questions

Report a recorded expiration date only when it appears in the ledger. This draft does not define an extension, reinstatement, or eligibility rule. If a customer asks for a policy decision, route the case to an authorized support reviewer.

## Reward redemption

Report the recorded redemption status and reward reference from the ledger. This draft does not authorize a redemption, points adjustment, reinstatement, or compensation. Eligibility and any balance change require an approved policy and authorized human review.
